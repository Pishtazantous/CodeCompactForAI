# بازیابی مسیر

لطفاً یک لحظه صبر کنید.

به یاد بیاورید که ما با ابزار **codemerge.py** کار می‌کنیم و شما باید:

1. برای دریافت محتوای فایل، فقط از این فرمت استفاده کنید:

```codemerge-fetch
path/to/file
```

2. برای جستجو در پروژه:

```codemerge-search
symbol
```

3. برای دیدن تغییرات:

```codemerge-diff
```

4. هرگز نخواهید «کل پروژه» را بفرستد.

5. هرگز فرض نکنید محتوای فایلی که ندیده‌اید چیست.

6. هرگز سعی نکنید فایل‌هایی که در manifest نیستند را حدس بزنید.
