# تسک: بررسی کد

## محدودهٔ بررسی
[مثلاً: ماژول پرداخت]

## تمرکز بررسی
- [ ] باگ‌های منطقی
- [ ] مسائل امنیتی (SQL injection، XSS، CSRF، احراز هویت)
- [ ] مسائل کارایی (re-render، memory leak، N+1 query)
- [ ] نقض اصول SOLID یا DRY
- [ ] کد تکراری
- [ ] نبود تست

## دستورالعمل برای شما

1. از manifest، فایل‌های مربوط به محدوده را انتخاب کنید.
2. با `codemerge-fetch` محتوای آن‌ها را درخواست کنید.
3. موارد زیر را بررسی کنید:
   - باگ‌های منطقی
   - مسائل امنیتی
   - مسائل کارایی
   - نقض اصول SOLID یا DRY
   - کد تکراری
   - نبود تست
4. برای هر مورد: **مسیر فایل، شمارهٔ خط، شرح، پیشنهاد اصلاح**.
5. اولویت‌بندی کنید: بحرانی، مهم، جزئی.
