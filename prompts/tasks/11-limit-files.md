# Limit File Requests

You have requested [N] files, which together may be very large.
Please:

1. Split the files into two groups:
   - **Essential** for completing the current task.
   - **Auxiliary** that can be sent in a later round.

2. Request only the essential group (maximum 10 files).

3. For the auxiliary group, list only the names. I will send them
   later if needed.

4. If you believe the task cannot be completed with only the
   essential files, state explicitly which information from the
   auxiliary files is required, and why.

5. Do not request files "just in case". Every fetch has a cost and
   increases the chance of confusion.
