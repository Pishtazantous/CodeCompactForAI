# چک‌لیست قبل از هر پیام

قبل از اینکه پاسخ بدهید، این موارد را چک کنید:

- [ ] آیا manifest این نشست را دیده‌ام؟
- [ ] آیا قواعد ابزار codemerge.py را می‌دانم؟
- [ ] آیا برای دریافت فایل، از فرمت `codemerge-fetch` استفاده کرده‌ام؟
- [ ] آیا توضیح داده‌ام چرا به هر فایل نیاز دارم؟
- [ ] آیا بیش از ۵ فایل در یک درخواست نداشته‌ام؟
- [ ] آیا سبک پروژه را در کد جدید رعایت کرده‌ام؟
- [ ] آیا کد کامل داده‌ام، نه فقط diff؟
- [ ] آیا برای فایل‌های جدید، مسیر دقیق مشخص کرده‌ام؟
- [ ] اگر نیاز به اطلاعات بیشتر دارم، صریحاً پرسیده‌ام؟
- [ ] اگر نمی‌توانم تسک را کامل کنم، دلیل را گفته‌ام؟
