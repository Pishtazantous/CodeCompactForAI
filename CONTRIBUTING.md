# Contributing

## Before You Start

For anything larger than a typo, open an issue first. This avoids duplicate
work and ensures the change is in scope.

## Development

    git clone https://github.com/USERNAME/CodeCompactForAI.git
    cd CodeCompactForAI
    pip install -e ".[dev]"
    pytest tests/ -v

## Pull Requests

- One concern per PR
- Tests for new behavior
- No changes to the public interface without discussion
